# DigitalHub ZA – Official Website

**Live URL**: [https://digitalhubza.co.za](https://digitalhubza.co.za)  
**Purpose**: Showcase services, attract clients, and provide contact functionality for **DigitalHub ZA**, a South African digital solutions provider specializing in **web development, automation, data analytics, and design**. 

---

## 📌 Overview

This is a **custom-built, responsive, single-page marketing website** designed to highlight DigitalHub ZA’s core offerings with a modern, performance-optimized frontend. The site features smooth animations, video backgrounds, interactive counters, and a functional contact form—without relying on heavy frameworks or CMS platforms.

---
## 🎯 Core Focus Areas
- **Website Development**: Custom, responsive, and scalable websites built with modern UI/UX principles.
- **Automation**: Streamlining business workflows using smart automation tools to save time and reduce errors.
- **Data Analytics**: Transforming raw data into actionable insights using tools like Power BI, SQL, and Metabase.
- **Graphic & UI/UX Design**: Creating visually compelling and user-friendly digital experiences using tools like Figma.
- **SEO Optimization**: Improving online visibility and organic traffic through technical and content-based SEO.
- **Account Management**: Providing end-to-end client support and strategic guidance throughout the project lifecycle.
    
---
## 🛠️ Key Features

### ✅ Core Sections
- **Hero**: Fullscreen looping background video with overlay text and CTA.
- **About**: Company overview + animated stats (dashboards, websites, automations).
- **Services**: 6 service cards (Web Dev, Data Analysis, Graphic Design, SEO, Automation, Account Management).
- **Process**: 4-step client journey (Discover → Plan → Build → Launch).
- **Contact**: Phone, email, hours + embedded contact form with auto-response.
- **Forex**: Live exchange rates(Gold & Silver)
- **Footer**: Copyright + social links (Facebook, Instagram, WhatsApp).

### ✅ Technical Highlights
- **Preloader** with animated page-flip effect.
- **Lazy-loaded images** and **optimized video** (`webm` + `mp4` fallback).
- **SEO-optimized** meta tags (Open Graph, Twitter Card, canonical URL).
- **Structured Data (JSON-LD)** for Organization schema (Google-friendly).
- **PWA-ready**: Includes `manifest.json` and theme color.
- **Mobile-first**, fully responsive design.
